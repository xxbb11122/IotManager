# Apple 轻毛玻璃 v1.2 独立功能演示

本工程按 v1.2 方案实现，使用当前 App 的原生 ES Module 页面、能力模型、DOM 协调器和 AI 控制器的**固定副本**。演示拥有独立依赖、构建与测试配置；可以复制整个目录单独使用。生产 `client/`、Android、后端与项目启动入口不引用此工程。

所有设备、天气、登录、LAN/BLE 和 AI 服务均在本地内存中模拟。无需账号、后端、硬件或 AI 密钥。AI 答案有“本地模拟回答”标记，快捷问题只填写草稿；仅点击发送才提交模拟问题。

## 轻毛玻璃与液态玻璃混合预览

本演示已接入 `simple-liquid-glass@5.3.0` 的原生 Web Components 入口，无需 React。全局采用轻毛玻璃与液态玻璃混用：设备列表、详情、AI、动态、添加、站点、天气和连接设置均使用半透明毛玻璃表面；卡片、按钮、分段控件、开关及 AI 输入面板叠加液态边缘，手机导航和桌面侧栏的选中区域使用移动玻璃指示器。光学表面位于真实文字和控件下方，设备数值、命令回执和 AI 内容保持可读。

设备详情使用一块连续玻璃面板，连接、状态、控制、命令与动态通过标题和细分隔线组织，不再重复嵌套卡片。期望状态与已上报状态在常用手机宽度并排显示，窄屏与大字体自动纵向排列；状态名称和模式值沿用设备能力定义。控制区统一使用玻璃开关、渐变轨道与半透明滑块，以及一组连续的模式选择控件，保留原生滑动条的拖动、键盘和回执交互。

天气页优先展示温度、天气、湿度、气压、风速与海拔，概览和环境提示共用同一套玻璃材质。位置设置置于下方，手动坐标与时区可折叠展开；保存或刷新后保持展开状态。没有预报数据时显示简短说明，避免两个空预报框占据页面。顶部工具条、测试台和材质对比弹窗也使用相同材质。

顶栏点击 **材质对比**，可在相同背景下查看原版轻毛玻璃与新版液态玻璃，并切换 **轻毛玻璃 / 液态玻璃 / 实色**。点击 **返回 App 查看效果** 后，材质选择应用于各页面。连接设置内的实色选项仍会关闭折射；重置演示恢复混合玻璃预览。动画减量只控制运动，高对比度模式使用实色。

材质对比中的 WebGL 只捕获一小块静态装饰背景，关闭对比窗口即释放渲染资源。App 表面使用 SVG 折射，未支持的浏览器使用毛玻璃降级；没有持续噪声动画，也不持续捕获设备遥测或 AI 内容。页面内的数据刷新复用已有光学表面。移动端真实 WebView/PDA 的性能仍需真机验证。

## 启动演示

使用 Node.js 22 或更高版本。仓库不跟踪 `dist/` 构建；首次从 GitHub 检出后可双击 `start-demo.cmd` 自动安装依赖并构建，或先在本目录运行 `npm ci --no-audit --no-fund`、`npm run build`，再运行：

```powershell
node scripts/serve.mjs
```

浏览器打开 **http://127.0.0.1:5188/**。终端按 Ctrl+C 停止。此服务器只监听本机，不开放现场设备连接。端口被占用时先关闭原演示终端，或设置 `$env:GLASS_DEMO_PORT=5198` 后运行同一命令。


浏览器测试默认使用已启动的本目录开发服务器；未启动时自动启动。首次在新电脑运行浏览器测试，先执行 `npx playwright install chromium`。单元测试不需要浏览器。测试报告在 `verification/`，失败截图与 trace 在 `test-results/`，交互报告在 `playwright-report/`。

静态构建服务器启动后，可运行 `node scripts/verify-built.mjs` 复现构建包冒烟测试和截图。该脚本需要本目录的 Playwright 开发依赖；正常运行构建包不需要这些依赖。[本次验证记录](VERIFICATION.md)列出实际执行结果与边界。

## 手动测试顺序

1. **设备控制**：打开首张照明卡片，操作电源、照明强度或模式。拖动时只预览；提交后显示目标值并暂时禁用控制。等待模拟 ACK 后才更新已上报值。第二指介入或手势取消不产生命令。
2. **回执分支**：打开顶部“演示测试台”，选择成功、失败或结果未确认，再返回页面操作。失败支持明确重试；结果未确认保留原上报值，不自动重发。命令结果在提交时固定，更改测试台不会改写已提交命令。
3. **异常与只读**：测试台提供缓存只读、模拟断线、未知蓝牙 Profile、非法范围和未知上报值。页面显示原因，并阻止不可用控制。
4. **AI**：切换到 AI，点击快捷问题，确认草稿与字符计数更新。发送后显示等待状态和模拟答案。测试台可选择处理中、失败、5 秒限流；原请求查询不会再次发送问题。可测试停止本地等待、明确重试、会话历史和性格版本。性格管理演示版本与作用域流程，固定规则回答不会执行自定义指令。
5. **站点与身份**：顶栏站点入口可切换两个独立演示站点。切换、退出登录或重置会结束旧命令等待；旧回执不能更新新站点。模拟退出后设备只读、AI 要求登录；模拟登录可恢复访问。
6. **添加与链路**：添加页可演示 LAN 发现→认领→列表新增，以及模拟 BLE 选择、断开、重新连接。不会调用浏览器蓝牙、定位或原生接口。
   顶栏天气入口支持刷新固定天气样例、使用演示位置与手动保存模拟坐标；修改坐标不会请求真实天气。
7. **材质与布局**：顶栏“连接设置”中的“界面显示”提供自动/实色及动画减量开关。材质与动画独立；导航保留材质选择。测试台支持 150%/200% 文字、安全区模拟。浏览器调整宽度可检查 320/390/414/768/820/1024/1440 px；卡片依据内容区域宽度选择一列或两列。
8. **记录与复位**：测试台显示命令提交、AI 发送、原请求查询计数与事件，可导出 JSON 记录；“重置演示”清除状态。刷新也会恢复初始数据。所有历史与设置只在本页面会话内保留。

## 文件结构与验证边界

- `src/framework/`：App UI 相关模块的固定副本；仅在该副本接入滑块与 AI 片段，并调整详情、天气、顶栏、显示设置和模拟文案。
- `src/liquid-glass.js`、`src/glass-surfaces.js`、`src/css/liquid.css`、`device-detail.css`、`weather.css`：材质切换、共享光学表面及详情/天气布局。
- `src/demo-store.js`、`src/mock-ai.js`：本地模拟数据、回执状态机、AI 请求与恢复记录。
- `src/main.js`：演示事件桥接与测试台；普通页面不暴露控制器全局变量，`?test=1` 为自动测试入口。
- `source-provenance.json`：来源文件与方案摘要，用于识别复制基线；运行演示不读取生产源码或开发文档。
- `test/`、`e2e/`：框架回归副本与演示功能测试。
- `dist/`、`scripts/serve.mjs`：可独立运行的静态构建与无第三方依赖的本机服务器。

浏览器测试覆盖模拟业务流程与响应式布局，不能代替 Android/PDA 真机的安全区、软键盘、TalkBack、WebView 性能或真实 BLE/API 回执验收。本演示没有接入 APK，也没有改变生产 App 的功能。
